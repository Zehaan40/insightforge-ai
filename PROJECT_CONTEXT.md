# InsightForge AI — Project Context

## Project
InsightForge AI — AI Business Analyst Assistant

## Elevator Pitch
InsightForge AI turns natural-language business questions into validated SQL, data analysis, visualizations, and evidence-based insights—helping teams understand what happened and why.

## Goal
Build a portfolio-quality AI Business Analyst Assistant for the NVIDIA/Nebius Global AI Hackathon while learning the underlying concepts rather than blindly generating code.

## Core Workflow
User Question
→ Intent & Analysis Planning
→ SQL Generation
→ SQL Validation
→ Database Query
→ Python Analysis
→ Visualization
→ Evidence-Based Insights
→ Business Recommendations

## Example
User:
"Why did revenue drop in March?"

System should:
1. Understand the question
2. Identify relevant metrics/dimensions
3. Generate SQL
4. Validate SQL
5. Query the database
6. Analyze the returned data
7. Identify measurable drivers
8. Generate visualization(s)
9. Explain the findings
10. Provide actionable follow-up/recommendations
